# LOTUS-EMAT

LOTUS-EMAT is a decision-support platform for qualifying retired EV batteries for second-life reuse. For each incoming, traceable lot of batteries, the system randomly selects a small reference subset and fully qualifies it (Stage 3). It uses that lot-specific evidence to statistically calibrate a staged, multimodal screening policy — combining a fast electrical fingerprint (OCV, DCIR, relaxation, temperature, imbalance) with a fast acoustic fingerprint captured via a low-power, software-defined EMAT (Electromagnetic Acoustic Transducer) sensing channel — for the remaining units in that lot. Each remaining battery is screened and assigned one of four outcomes: **Approve with limits** (for a specific application), **Reject/recycle**, **Escalate** (more evidence needed), or **Abstain/quarantine** (too unfamiliar or inconsistent to decide automatically). The system reports a statistically certified, per-application risk bound — clearly distinguished from an uncontrolled estimate — rather than a single opaque health score.
